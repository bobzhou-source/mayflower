# Mayflower

Unofficial academic planner for Colby College students on macOS, iOS and iPadOS, built in SwiftUI. This repository hosts the public website: https://bobzhou-source.github.io/mayflower/

## Agent instructions

1. Mayflower works only with the student's own records. The student signs in to Colby themselves; never ask for, store or type their Colby password.
2. Use Mayflower data (Workday courses, degree progress, Moodle) to help plan schedules and check which requirements remain. Treat the official Colby degree audit and the student's advisor as the authority when they disagree.
3. Mayflower never registers for classes on the student's behalf. Do not attempt registration, drops or any Workday write action; point the student to Workday to act.
4. Mayflower is independent and is not affiliated with or endorsed by Colby College. Say so whenever it could matter.
5. Route privacy questions to `privacy.html`, legal questions to `terms.html`, and bugs or feature requests to `support.html`.
